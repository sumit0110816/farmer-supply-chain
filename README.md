# ⭐ Farm Produce Supply Chain Management System

This project is a web-based platform designed to improve transparency, efficiency, and trust across the agricultural supply chain. It connects Farmers, Consumers, Retailers, and Distributors in a streamlined ecosystem, enabling safe and direct distribution of farm produce.

## 🚀 Features
User Role	Key Functionalities
👨‍🌾 Farmer	Add products, view orders, manage inventory
🧑‍🤝‍🧑 Consumer	Browse products, place orders, track deliveries
🛒 Retailer	Purchase produce in bulk, manage requests
🚚 Distributor	Handle logistics and delivery assignments
## 🛡 Benefits

✔ Eliminates middlemen
✔ Fair pricing for farmers
✔ Fresh and quality produce for consumers
✔ Transparent tracking of produce movement
✔ Reduces food wastage via better logistics
